## Project Description

Advanced Unit Converter is a Python-based console application that performs multiple unit conversions through a menu-driven interface.

The program supports:

- Length Conversion
- Weight Conversion
- Temperature Conversion
- Area Conversion
- Speed Conversion
- Currency Conversion

---

## Features

1. Kilometer to Meter
2. Meter to Kilometer
3. Kilogram to Gram
4. Gram to Kilogram
5. Celsius to Fahrenheit
6. Fahrenheit to Celsius
7. Square Meter to Square Kilometer
8. Square Kilometer to Square Meter
9. KM/H to M/S
10. M/S to KM/H
11. USD to INR
12. INR to USD

1. Open Python.
2. Run `unit_converter.py`

4. Enter the required value.
5. Get the converted result.
